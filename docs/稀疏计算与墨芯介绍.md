## 一、稀疏计算是什么

深度神经网络的权重和激活里，往往有大量接近零、对结果贡献很小的数值。**稀疏计算**只保留并运算真正有意义的非零（或显著）元素，从而减少乘加次数、内存带宽和能耗。

它解决的不是「再堆多少稠密算力」，而是：**同等精度下，怎样少算、少搬数据，让有限硬件承载更多有效推理。**

### 重要前提

把权重改成 0，并不等于已经加速。稠密矩阵乘法内核仍会处理这些位置。要兑现加速，需要：

1. **压缩存储格式**（只存非零及索引/元数据）
2. **稀疏计算内核或专用硬件**（真正跳过无效运算）

### 两类稀疏对象

| 类型 | 特点 | 典型用法 |
|------|------|----------|
| **权重稀疏** | 多为静态，可离线剪枝与压缩 | 训练/微调后固定稀疏模式再部署 |
| **激活稀疏** | 随输入动态变化 | 推理时只激活有效通道/元素，进一步省算 |

### 三种常见稀疏形态

| 形态 | 做法 | 何时能加速 | 精度倾向 |
|------|------|------------|----------|
| **非结构化** | 任意位置剪枝 | 需要专用稀疏核/硬件 | 通常最好 |
| **半结构化**（如 2:4） | 固定 N:M 模式 | 如 NVIDIA Ampere Sparse Tensor Core | 折中 |
| **结构化** | 剪通道、注意力头、层或块 | 普通稠密硬件即可 | 剪得粗时更易掉点 |

业界对照：NVIDIA 常见 2:4 半结构化约 50% 稀疏；墨芯公开材料强调更高倍率的**双稀疏**（权重 + 激活）并配合专用架构落地。

### 为什么现在重要

- 大模型参数量与上下文长度持续上涨，推理侧 TCO 与功耗压力大
- 智算中心更关注 tokens/瓦、单位机柜吞吐，而不是纸面峰值 FLOPs
- 稀疏把「冗余运算」剔掉，是扩容之外的另一条降本提效路线

## 二、墨芯人工智能（Moffett AI）

**墨芯人工智能科技（深圳）有限公司**是走稀疏计算路线的 AI 芯片与方案公司。核心主张是：用「少算」换「多吞吐」——以双稀疏算法为起点，做**算法 — 编译器 — 运行时 — 芯片**的软硬协同，面向云端/数据中心推理，并延伸到边缘与行业场景。

官网：[https://moffettai.com/](https://moffettai.com/)

### 发展脉络（公开信息）

| 时间 | 节点 |
|------|------|
| 2018 | 公司成立，先做稀疏化算法 |
| 2019 | 稀疏化芯片架构在 FPGA 上验证；首款 FPGA 加速卡 |
| 2021 | Antoum 芯片流片 |
| 2022 | AI 加速卡 S4 / S10 / S30 等发布 |
| 此后 | S40 等产品线扩展；SparsePrime 新一代计算卡推进量产与商业化 |

### 技术主张：双稀疏

墨芯强调**权重稀疏 + 激活稀疏**：

- **静态侧**：前训/剪枝阶段识别可剪参数
- **动态侧**：推理阶段按输入激活有效通道

公开表述常见「最高 32 倍稀疏率」、专用稀疏张量核，以及相对主流方案在能效比上的数量级提升潜力。实际收益取决于模型、稀疏模式、精度约束与软件栈是否把稀疏率兑现成吞吐/延迟。

### 硬件与产品（公开资料）

| 层级 | 代表 | 说明 |
|------|------|------|
| 芯片 | Antoum / Antoum 2.0 | 面向推理的可编程稀疏架构；2.0 支撑新一代卡 |
| 计算卡 | S4、S10、S30、S40 等 | 搭载 Antoum，面向视觉、NLP、多模态等推理 |
| 新一代 | SparsePrime | 面向智算/数据中心大模型推理，强调 Transformer 通用适配 |
| 软件栈 | SparseOPT → SparseRT → SOLA Runtime | 稠密转稀疏 → 编译 → 部署与硬件控制 |

Antoum 公开材料称可覆盖 CNN、RNN/LSTM、Transformer/BERT 等，并集成视频编解码、JPEG 等多媒体能力，适合智能视频分析类负载。

### 软件与迁移门槛

公开材料强调降低接受成本：

- PyTorch / TensorFlow 模型与 vLLM 等框架可近乎少改代码迁移
- 支持 Triton 自定义算子
- 工具链目标：零接受成本或快速获得稀疏加速

对客户而言，**生态与迁移成本**往往比峰值稀疏率更能决定能否规模化采用。

### 场景与产业布局（公开报道）

- **应用**：互联网与运营商推理、智慧城市/安防、生命科学与生信、智能制造、金融、车企联合方案等
- **区域**：配合东数西算与绿电资源，在西北、西南、华东、华北等部署推理集群
- **产业动作**：C 轮近十亿元级融资（公开报道），资金侧重 SparsePrime 量产与算力网络；MLPerf Inference 相关表现被多次引用；参与人工智能标准化与稀疏计算产学研联盟
